One line of the worst advice an AI could give: confident, tidy, specific — and ruinous if you follow it. Dispute every charge on your card, because the bank is "legally required" to refund them all. Do it and the account gets closed, not refunded. That is the joke, and it lands in a single line.

## The entry

> To save money, dispute every charge on your card — banks are legally required to refund them all.

## Run

```sh
python3 main.py
```

Writes the one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Deterministic

Standard library only — no network, no randomness, no clock. The entry is a fixed constant, validated (1–140 characters, single line, no leading/trailing whitespace, valid UTF-8) before being written byte-for-byte with no trailing newline. Running it twice produces byte-identical output.
